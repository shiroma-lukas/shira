How it works Safety Shira Cloud GitHub

An AI agent team that turns issues into pull requests.

You describe the work in an issue. Shira's agents fix it in an isolated sandbox, run your tests, and open a pull request with the evidence and the cost. People discuss, decide, and merge. Agents do the work.

View on GitHub Shira Cloud

How it works

One task, one branch, one isolated workspace. Every step is recorded, so the reasoning behind any pull request can be reconstructed.

Point it at an issue

shira submit --issue 12. The agent gets the issue's full text and a budget.

An agent works in a sandbox

A fresh clone in its own container. It edits, runs commands, and commits, but can't push.

The platform checks the work

Rebase on main, run your test suite, scan the diff for secrets. In code, not by asking the agent nicely.

You review the PR

Summary, test evidence, and cost in the description; Fixes #12 links the issue. Merging is yours.

What a run looks like

A real run on our playground repository: a bug report about letters like ß and ø breaking URL slugs, fixed end to end.

$ shira submit --repo shiroma-lukas/shira-playground --issue 3
queued   worker   "Resolve issue #3: Slugs break on letters that don't decompose"

$ shira show 5d1c5dff
done     PR #4  "Transliterate non-decomposing letters in slugify"
  attempts 1, spend $0.02 of $5 budget, 13,139 tokens
  tests passed after rebase · diff scanned for secrets: none found

Built to be trusted with your code

Agents run untrusted code by nature. Shira assumes that and contains it.

gVisor sandboxes

Each task runs in its own gVisor container with every Linux capability dropped and hard CPU, memory, and time limits.

Allowlisted egress only

Sandboxes have no route to the internet. One proxy lets each sandbox reach only its allowlisted hosts, and never private or cloud-metadata addresses.

Agents can't push or merge

Git credentials are short-lived, scoped to one repository, and used only by the platform after the agent has exited.

Budgets with hard stops

Per-task dollar, token, and time limits, a monthly ceiling, and a kill switch that pauses every agent at once.

Open source, or let us run it

The agent platform is open source. Shira Cloud operates it for you.
